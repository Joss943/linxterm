Free software for Linux · version 1.3

All your servers, in a single window.

LinXterm is a tabbed terminal that brings together SSH, an SFTP browser, X11 forwarding, RDP and VNC remote desktops, network tools, servers and SSH tunnels. Its interface is inspired by MobaXterm, built natively for Linux.

Install LinXterm View the code on GitHub

GPL-3.0 license · Free Pascal, GTK 3 and VTE · X11 and Wayland

Everything you need to work remotely

No more juggling a terminal, an SFTP client, an RDP client and a handful of network tools.

Tabbed terminals

Local and remote terminals, numbered tabs you can detach and color. The Split view shows 2 or 4 terminals, and MultiExec types the same command on several servers at once.

Saved sessions

SSH, Telnet, Mosh, RDP, VNC, FTP, SFTP, serial port, shell, files and web browser, organized in folders. Passwords stay in the desktop keyring. Import from MobaXterm, OpenSSH, PuTTY and Remmina.

Full SSH

X11 forwarding to display the server's graphical applications, jump host, private keys, automatic reconnection, an SFTP browser that follows the terminal and server monitoring (CPU, RAM, disk, network).

Built-in tools

Network and port scanner, graphical ping, traceroute, open ports, Wake-on-LAN, subnet calculator, SSH key generator, text editor, file comparison and process list.

Servers and tunnels

One-click HTTP, FTP, TFTP, SSH and iperf3 servers to share files on the local network. Local, remote and SOCKS SSH tunnels managed graphically, with automatic start.

Made for everyday use

Macros, command palette (Ctrl+Shift+P), highlighting of errors and warnings, session logs, a notification when long commands finish, clickable links, light, dark or automatic theme.

Installation

LinXterm builds from source in about a minute; the installation itself needs no administrator rights.

  1. Install the Free Pascal compiler

    GTK 3 and VTE already come with the usual desktops; no development package is needed.

    sudo dnf install fpc gtk3 vte291
    sudo apt install fpc libgtk-3-0 libvte-2.91-0
    sudo pacman -S fpc gtk3 vte3
    sudo zypper install fpc libgtk-3-0 libvte-2_91-0

  2. Download and install LinXterm

    The program stays in its folder; a launcher is added to the applications menu and to the desktop.

    git clone https://github.com/Joss943/linxterm.git
cd linxterm
./install.sh

  3. Add the optional tools

    Some features use external programs when they are installed. If one is missing, LinXterm says so, and the Packages button of the toolbar installs the rest.

    FeaturePrograms or libraries
    SSH, SFTP, tunnelsssh, sftp (OpenSSH), sshpass, mosh

    Built-in web browserWebKitGTK 4.1

Getting started

The essentials, from your first terminal to driving several servers.

  1. Open a local terminal

    The Start local terminal button of the home tab, the Enter key or Ctrl+Shift+T.

  2. Connect right away

    Type user@server, rdp server or sftp server in Quick connect, top left, then Enter. The same field also filters your sessions.

  3. Save a session

    Session button, pick the type, enter the server and the user. Double-click it in the Sessions panel to open it, right-click to edit it or file it in a folder.

  4. Transfer files

    With an SSH session, the Sftp tab of the side panel shows the server's files: drag and drop to upload or download.

  5. Run a remote graphical application

    With X11-Forwarding checked (the default), type for instance gedit on the server: the window opens on your desktop.

  6. Drive several servers

    Split shows 2 or 4 terminals side by side; MultiExec sends your typing to all of them. The Receive input box leaves one out.

  7. Tunnels, servers and tools

    Tunneling and Servers buttons of the toolbar, Tools tab of the side panel.

  8. Find a command

    Ctrl+Shift+P opens the palette: type a few letters of a session, a tab or a command.

  9. Customize

    Settings for the font, colors, prompt and logs; View > Skin for the light, dark or automatic theme.

Privacy and GDPR

LinXterm collects no personal data: everything it saves stays on your computer, and nothing is sent to its author.

No data collection

No account, no telemetry, no usage statistics, no ads. LinXterm never contacts a server on its own: it only connects to the machines you open (SSH, RDP, VNC…) and, when you ask for it, to your distribution's repositories (Packages button).

Data kept on your computer

In ~/.config/linxterm/: settings, sessions (name, server, user, options), macros, tunnels, servers, recent sessions and tabs to reopen. The files are readable by you only.

Passwords

Stored in the desktop keyring (GNOME Keyring, KWallet) as “LinXterm password”, never written in plain text, never exported or imported. Without a keyring, an obfuscated file is used only if you turn it on.

Session logs

Off by default. Once turned on, they are written to ~/Documents/LinXterm/logs (or the folder you choose), a private folder. They may contain personal data shown in your terminals: delete them when you no longer need them.

This website

No cookies, no audience measurement, no external resources. Only your language choice is kept in your browser, and it is never sent anywhere. The site is hosted by GitHub Pages: GitHub may record technical data (IP address) to secure the service, under its privacy statement.

Your rights

The author holds no data about you: there is nothing to access, correct or erase on their side. If you use LinXterm at work, your organization remains responsible for the data it processes with it (logs, sessions). Any question: the project's GitHub issues.

Erase all LinXterm data

rm -rf ~/.config/linxterm ~/Documents/LinXterm/logs

Then delete the “LinXterm password” entries in the Passwords and Keys application (Seahorse) or in KWallet.
